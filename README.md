# Кто прав в семье?

Шуточный трекер: тапом отмечаем, кто в очередной раз оказался прав — тёща, муж,
жена, мама, папа и любой другой персонаж, которого добавишь. Есть недельная
статистика с шуточными ярлыками, достижения и общий рейтинг «Итоги недели».

Всё приложение — статичный PWA (HTML/CSS/JS), никакого сервера: данные
хранятся локально в браузере/приложении (`localStorage`), сеть не нужна.

## Структура

- `index.html` — разметка всех экранов (список, карточка персонажа, итоги недели, модалка добавления).
- `css/style.css` — стили, яркая «мемная» палитра.
- `js/app.js` — вся логика: хранение, статистика, тапы, достижения.
- `manifest.json` — PWA-манифест (иконки, цвета, режим standalone).
- `sw.js` — service worker для офлайн-кеша.
- `icons/` — иконки 192/512 и maskable-версии.

## Как проверить локально

```bash
cd kto-prav
python3 -m http.server 8080
# открыть http://localhost:8080 в браузере (лучше в режиме мобильного экрана)
```

## Как собрать APK/AAB через PWABuilder

1. Выложи папку куда-нибудь с HTTPS (GitHub Pages — самый простой вариант,
   особенно раз у тебя уже есть GitHub-токен под рукой):
   - создать репозиторий, закинуть содержимое этой папки в корень (или в `docs/`),
   - включить GitHub Pages для ветки/папки.
2. Зайти на https://www.pwabuilder.com, вставить URL опубликованного сайта.
3. Убедиться, что PWABuilder видит манифест и service worker (зелёные галочки).
4. Раздел **Android** → **Generate Package** → выбрать "Trusted Web Activity" (TWA).
5. Скачать пакет, там будет:
   - подписанный/неподписанный AAB (для загрузки в Play Console),
   - `assetlinks.json` — его нужно выложить на сайт по пути
     `/.well-known/assetlinks.json`, чтобы приложение открывалось без адресной строки
     (Custom Tabs), иначе после установки из Play будет видна строка браузера.
6. Загрузить AAB в Play Console (внутреннее тестирование → потом продакшн).

Если после публикации в Play приложение всё равно показывает адресную строку —
это почти всегда проблема с `assetlinks.json` или подписью пакета (Play App
Signing переподписывает APK/AAB своим ключом, из-за чего digest в
`assetlinks.json` перестаёт совпадать). Это отдельная известная проблема,
которую можно решить точечно, когда дойдём до публикации.
